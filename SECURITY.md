# Security

Do not paste credentials, matched text, or personal data into an issue. Report a reproducible bug using synthetic inputs. For a live credential exposure, revoke the credential through its provider before sharing a redacted report.

This scanner is intentionally conservative and incomplete. Reports contain paths and content fingerprints. Treat them as private when filenames are sensitive. It performs read-only Git operations and never executes repository hooks or project code.

## Reporting a vulnerability

Use [Security > Report a vulnerability](https://github.com/Jgolding1998/repo-preflight/security/advisories/new) to send a private report. Do not submit vulnerability details through the public feedback form.

Include the affected version, platform, expected behavior and a synthetic reproduction. Leave out credentials, personal information and private files.
